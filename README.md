A budgetting app that will split a paycheck into buckets
Each time a purchase is made, the value of that purchase is removed from that buckets budget
A push notification is sent to the user notifying them of the purchase and of the remaining balance
This is meant to ensure more responcible use of money

Technologies:
Flask backend
React Frontend(React PWA to allow for phone integration)
JWT Tokens(used for authentication)
Hurdle: May have to load the token in memory
